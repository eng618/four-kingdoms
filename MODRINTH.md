# 👑 Four Kingdoms

Four lore-rich kingdoms, twelve hero gear sets, and armor that fights back. A **Minecraft 1.21.1 (NeoForge)** mod adding custom armor, weapons, tools — each with its own set bonus — forged from the powers of the four realms.

> The project description on this page is synced automatically from the mod's release pipeline.

## ✨ Dream Kingdom

Hope, light, and ethereal crystal — plus its shadow mirror.

| Hero | Gear | Set bonus (scales with pieces worn: 25% each, full set always triggers) |
| --- | --- | --- |
| **Daydream** | Spear (extended reach), full armor + tool set | Speed II + Regeneration I, every 20s |
| **Nightmare** | Sword, full armor + tool set | Blocks Wither / Poison / Slowness outright, cleanses lingering effects |

## 🔥 Element Kingdom

Nine heroes of primal force, each with armor, signature weapon, tools, and a matching bonus:

| Hero | Weapon | Bonus |
| --- | --- | --- |
| **Flare** (fire) | Sword | Fire Resistance |
| **Crystal** (ocean) | Trident | Water Breathing + Dolphin's Grace |
| **Speed** (storm) | Longsword | Speed + Haste |
| **Black** (shadow) | Blade | Invisibility + Night Vision |
| **Pearl** (ender) | Scythe | Slow Falling, no ender-pearl damage |
| **Lazuli** (frost) | Sickle | Attackers are chilled with Slowness |
| **Leafy** (nature) | Spear | Regeneration + Saturation |
| **Sylvia** (royal) | Sword | Absorption hearts |
| **Sunshine** (light) | Sword | Night Vision, cleanses Darkness & Blindness |

Ancient relics stir below… new hero gear arriving in a future release.

## 📦 Requirements

- Minecraft **1.21.1**
- NeoForge **21.1.247** or newer
- Java **21**

## ⬇️ Install

1. Install NeoForge for 1.21.1.
2. Drop the downloaded `.jar` into your `mods` folder.
3. Find everything in the **Four Kingdoms** creative tabs, or craft it in survival.
