# Explanation: Lore of the Four Kingdoms

* **Dream Kingdom** — hope, light, ethereal crystal. Heroes: Daydream (implemented, amethyst+diamond, luminous white/violet) and Nightmare (shadow mirror, cleanse/resist fantasy).
* **Element Kingdom** — primal fire, storm, earth, ocean (+5 more sub-elements for the 9-hero roster). Materials should read elementally (blaze, copper/storm, iron/earth, prismarine/ocean…).
* **Wild Kingdom** — untamed nature, beast armors, druidic weapons. No heroes defined for v1; tab reserved.
* **Forgotten Kingdom** — ancient relics, subterranean shadow magic. One hero for v1 (echo/sculk-infused).

Lore drives repair ingredients, colors, and set-bonus identity — mechanics follow fantasy, not the reverse.
